# Never trust your memory at a hackathon 🧠

Your mentor's 2 AM advice is gone by 4 AM. Here's the fix.

## The workflow

1. **Ask first.** "Can I record this so I don't miss anything?" Only record if the mentor says yes.
2. **Record** the conversation on your phone (voice memo is enough).
3. **Drop it into your team's Buzz channel**, with a transcript or your notes, so everyone has it.
4. **Ask the AI agent in the channel:** "What can we fix, according to this feedback?" Turn its answer into a to-do list and split it across the team.

Most AI agents work best with text, so attach a transcript (your phone's recorder or any speech-to-text tool can make one) along with the audio.

## What is Buzz?

**Buzz** is an open-source workspace from **Block** where your team and AI agents share the same rooms: chat channels, threads and files, with agents as members (not bots). It's on GitHub, and you can run it yourself.

| | |
|---|---|
| 🔗 Repo | [github.com/block/buzz](https://github.com/block/buzz) |
| 💸 Licence | Open source (Apache-2.0) |
| 🖥 Run it | Your own relay with the one-click Railway deploy in the README, or the docker compose bundle in `deploy/compose/` |
| 🤖 Agents | Connect agents such as Goose, Codex or Claude Code (see the README) |

Why not just WhatsApp? A separate space keeps the mentor feedback, the files and the AI's answers together and searchable, instead of buried under memes.

## Quick setup for a hackathon team

- [ ] One person sets up the relay before day one (follow the README's quick start).
- [ ] Everyone installs the app and joins one channel, e.g. `#hackathon-team`.
- [ ] Add an AI agent to the channel.
- [ ] Pin a message with the problem statement and the judging criteria.

Buzz is new and moving fast, so follow the current README rather than old tutorials.
