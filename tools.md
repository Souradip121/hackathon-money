# 12 tools your friend group should know 🧠

If your group knows these, you're ahead of your syllabus. What each one does, in one line, plus where to start.

| Tool | What it does | Free? |
|---|---|---|
| [NotebookLM, now Gemini Notebook](https://notebook.google.com/) | Study from your own PDFs, notes and lecture links: answers with citations, flashcards, quizzes, a podcast of your notes | Yes |
| [Google AI Studio](https://aistudio.google.com/) | Try Google's Gemini models, get an API key and build small AI apps in the browser | Yes, with limits |
| [Claude Code](https://claude.com/product/claude-code) | Anthropic's coding agent: it reads your project, edits files and runs commands from your terminal or editor | Needs a paid Claude plan or API credits |
| [Cursor](https://cursor.com/) | An AI code editor (looks like VS Code) that understands your whole codebase | Free plan with limited AI usage |
| [Antigravity](https://antigravity.google/) | Google's agent-first code editor: you give agents tasks and review what they did | Check the site for the current plan |
| [Ollama](https://ollama.com/) | Run open models like Gemma, Llama and Qwen on your own laptop, offline | Yes |
| [Hugging Face](https://huggingface.co/) | The home of open models and datasets, plus Spaces where you can try AI demos in the browser | Yes, paid extras |
| [Kaggle](https://www.kaggle.com/) | Datasets, notebooks with free GPU hours each week, competitions and short courses | Yes |
| [n8n](https://n8n.io/) | Automate workflows by connecting apps and AI (forms → sheets → email → WhatsApp) | Free to self-host; cloud is paid |
| [Lovable](https://lovable.dev/) | Describe a web app and it builds it, then you edit by chatting | Free plan with daily credits |
| [Nano Banana](https://gemini.google.com/) | Gemini's image model: create or edit images by describing them | Yes, in the Gemini app, with limits |
| [Suno](https://suno.com/) | Make a full song from a text prompt | Free plan with daily credits, non-commercial use |

## Where I'd start

1. **This week:** Gemini Notebook (NotebookLM) for your next exam, and Kaggle Learn's Intro to Machine Learning.
2. **For your projects:** Cursor or Antigravity to build, Ollama to run a model locally, Hugging Face to find one.
3. **For your club:** n8n to automate registrations, Nano Banana for the poster, Lovable for a quick event page.

Check each tool's pricing page before you rely on it. Free plans change.
