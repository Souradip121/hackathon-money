# 5 GitHub URL tricks that feel illegal to know 🚨

All five are free and work on **public** repos. The examples use Flask's repo, `github.com/pallets/flask`. Swap in any repo you like.

## 1. github.com → gitmcp.io

Change `github.com` to `gitmcp.io` and the repo becomes a remote MCP server. Add that URL to Cursor, Claude or VS Code and your AI agent can read the repo's real docs and code, so it stops making things up about the library.

- `https://github.com/pallets/flask` → [`https://gitmcp.io/pallets/flask`](https://gitmcp.io/pallets/flask)
- The page shows the exact config to paste into your AI tool.

## 2. hub → ingest

Replace `hub` with `ingest` and the whole repo turns into one text file you can paste into ChatGPT, Claude or Gemini.

- [`https://gitingest.com/pallets/flask`](https://gitingest.com/pallets/flask)
- Big repo? Filter by file type or size on the page so it fits in the chat.

## 3. hub → diagram

Replace `hub` with `diagram` to get an interactive architecture diagram of the codebase. Click a box to jump to that file.

- [`https://gitdiagram.com/pallets/flask`](https://gitdiagram.com/pallets/flask)

## 4. github.com → githubbox.com

Opens the repo in CodeSandbox, so you can run and edit it in the browser without cloning.

- [`https://githubbox.com/pallets/flask`](https://githubbox.com/pallets/flask)

## 5. Press `.` (or change .com to .dev)

On any repo, press the **.** key, or change `github.com` to `github.dev`. A full VS Code editor opens in your browser.

- [`https://github.dev/pallets/flask`](https://github.dev/pallets/flask)
- It's an editor, not a terminal: to run code, use Codespaces or trick #4.
