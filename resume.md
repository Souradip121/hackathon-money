# The resume template that puts wins above grades 📄

My 9.17 SGPA didn't get me my ISRO internship. My Smart India Hackathon 2024 win did. When I sent resumes with just my marks, I got rejected. When I led with the win and the projects, I got selected.

Recruiters spend about **7 seconds** on a first scan (Ladders eye-tracking study, 2018). Put the proof where those 7 seconds land: the top.

## The template

Copy this into Google Docs or Word, keep it to **one page**, and export a PDF.

```
YOUR NAME
email · phone · github.com/you · linkedin.com/in/you · your-portfolio.link

WINS
- Winner, <Hackathon> <Year>: built <what> for <who> in <N> hours
- Finalist, <Hackathon> <Year>: top <N> of <N> teams on <problem>

PROJECTS
<Project name>  ·  Live: <link>  ·  Code: <GitHub link>
- Built <what it does> for <who it's for>, using <stack>.
- <Impact with one real number: users, time saved, accuracy, money>.

<Project name>  ·  Live: <link>  ·  Code: <GitHub link>
- ...

EXPERIENCE (if you have any)
<Role>, <Company> (<months>)
- <What you shipped, with a number>.

SKILLS
Only what you've used in a project above: languages · frameworks · tools

EDUCATION
B.Tech <branch>, <college> (<year>)  ·  CGPA <x>
```

## Noob vs pro, line by line

| | Noob | Pro |
|---|---|---|
| **The project line** | "Participated in XYZ Hackathon 2026." | "Built an offline crop-disease app in 36 hours." Say what you built. |
| **The GitHub link** | A repo whose README says `npm install` | A README with a demo GIF, the problem in one line, a live link and "run it in 2 steps" |
| **The demo** | `localhost:3000` | A live link plus a 90-second demo video |
| **The impact** | "Made a website for farmers." | "Cut disease lookup from 5 min to 20 sec, tested with 40 users." |
| **The order** | Education and CGPA on top, projects on page 2 | Wins first, then projects, skills, education last |
| **The LinkedIn post** | A certificate photo and "Grateful for this opportunity" | What you built, what broke at 3 a.m., a 30-second clip, your team tagged |

(The crop-disease app is an example. Use your real numbers, never made-up ones. Interviewers ask about every line.)

## Before you hit send

- One page. PDF. File name: `FirstName-LastName-Resume.pdf`.
- Every link opens without a login: live demo, GitHub, portfolio.
- Every project has a number in it.
- No "hardworking team player": show it with a win instead.
- A wrong phone number or a dead link loses the interview. Click everything once.
